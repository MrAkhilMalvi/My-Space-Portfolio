## 🛠️ **Getting Started**  

### **Prerequisites**  
Ensure the following are installed:  
- **Node.js**  
- **npm** or **yarn**  
- **MongoDB**  

### **Steps to Run Locally**  

1. **Clone the Repository**  
   ```bash
   git clone https://github.com/MrAkhilMalvi/My-Space-Portfolio.git
   cd My-Space-Portfolio
   ```

2. **Install Dependencies**  
   ```bash
   cd client
   npm install
   cd ../server
   npm install
   ```

3. **Start the Development Server**  
   ```bash
   # Start client
   cd client
   npm start

   # Start backend server
   cd ../server
   npm run dev
   ```

4. **View in Browser**  
   Open `http://localhost:3000` to view the portfolio.
